## 新平台接入清单

1. 调研：平台是否有公开 API / 开放平台；确认网页端自动化的登录方式（扫码/账密）、验证码类型
2. 调研开源先例（GitHub 搜 `<平台> 自动投递`），确认频控参数与风控信号
3. 写 `references/<platform>.md`：搜索 URL 模板、城市代码、DOM 选择器、日上限、已知怪癖、选择器维护指引
4. 写 `scripts/<platform>/`：`_lib.py`（复用 boss 的会话/频控/台账模式）、`login.py`、`search.py`、`apply.py`
5. 更新本表与插件 README

## 通用安全约定（所有平台）

- 脚本只做 I/O，筛选与文案由 Claude 判断；默认人工确认制
- 日上限取「平台上限的 50-70%」，随机间隔，批次长休息
- 验证码/风控页 → 停止批次 + 截图 + 转人工
- 台账（`delivered.json`）按平台分 key 防重投
- 服务器 IP 会被识别（返回空数据或封控），只在本机运行；本机代理需关闭
