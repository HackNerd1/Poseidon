# 打招呼语模板库

> 与 `greeting-principles.md` 的标准配套使用。槽位用 `{花括号}` 标注，生成时按候选人的真实证据填充，禁止编造槽位内容。

## 主推版模板（100-130 字）

```
您好！{证据钩子：最强证据的事实陈述，含数字}——
{次级匹配点：1-3 个短语，各对应 JD 一条职责/要求}，{差异化条件：兼职/到岗}。
{匹配收尾：和您的招聘要求很匹配}，{行动请求：方便发您一份完整简历吗？}
```

### 槽位说明

| 槽位 | 要求 | 反例 → 正例 |
|------|------|------------|
| 证据钩子 | 事实 + 数字，≤ 40 字 | ~~我经验丰富~~ → 我交付过一个近 4 个月的 X 项目 |
| 次级匹配点 | 短语，回显 JD 关键词 | ~~精通各种技术~~ → 覆盖设计→开发→测试→运维全周期 |
| 差异化条件 | JD 明确要求才写 | 接受兼职 / 可随时到岗 |
| 匹配收尾 | 只出现这一次 | 和您的招聘要求很匹配 |
| 行动请求 | 明确、低成本 | 方便发您一份完整简历吗 |

## 超短版模板（70-80 字）

```
您好！{证据钩子}，{一个次级匹配点短语}，{差异化条件}。{行动请求}
```

超短版砍掉匹配收尾句（字数不够时优先砍它），证据钩子和行动请求必须保留。

## 变体模板

### 自研钩子变体（无商业交付时）

商业交付是首选钩子；只有自研项目时，用「完整度」补强度——数量、独立性、可验证产物（GitHub 链接、安装量）：

```
您好！我独立开发过 {N} 个完整的 {JD核心工具} 项目（{最有分量的一个：一句话产物描述}），
{次级匹配点短语}，{差异化条件}。和您的招聘要求很匹配，方便发您简历详聊吗？
```

### HR 回复后的展开版（第二轮）

HR 已表现出兴趣，此时才展开细节，仍按「证据 + 数字」展开：

```
谢谢回复！我展开说下 {最匹配项目}：{一句话背景}。我负责 {职责范围}，
关键成果：{数字化的 1-2 个成果}。简历已发送，期待进一步沟通。
```

### 已读不回跟进版（间隔 2-3 天）

只补一个新信息点，不重复原文，不催促：

```
您好，之前联系过您关于 {岗位名}。补充一点：{一个新的证据点，如 GitHub 链接 / 新的量化成果}。
如果岗位还在招人，方便发您一份简历吗？
```

## 真实案例（worked example）

**输入**：JD = 基于 Claude Code 完成流程设计/开发/测试/运维全周期，输出技术文档与自动化方案，保障稳定性，精通 Claude Code 1-3 年，API 调试，可兼职。
经历材料：1 个商业交付项目（Claude Code 自动化文档流水线，历时近 4 个月，交付物即技术文档）+ 2 个自研项目。

### ❌ 改前（断言开头 + 术语堆砌）

> 您好！这个岗位和我高度匹配——我就是「用 Claude Code 干活」的人：独立交付过 3 个 Claude Code 项目（插件大仓、自动化文档流水线、多 Agent 系统），熟悉 SKILL.md、hooks、子 Agent 编排、MCP 与 API 调试（REST/GraphQL/JSON-RPC）……

问题：开头断言（无效模板同款）；三个证据并列稀释重点；SKILL.md/JSON-RPC 等 HR 看不懂；没回应「兼职」。

### ✅ 改后（主推版，证据钩子 = 商业交付 + 职责同构）

> 您好！我刚交付过一个历时近 4 个月的 Claude Code 项目：为汽车电子团队开发「源码→模块/架构文档」的自动生成流水线，从流程设计、开发、测试到运维全周期由我负责，交付物就是可直接用于评审的技术文档。另有 2 个自研 Claude Code 项目。接受兼职，和您的招聘要求很匹配，方便发您一份完整简历吗？

改对点：
1. 钩子换成最强证据（商业交付 + 近 4 个月 + 全周期，对应 JD 第 1 条）
2. 「交付物就是技术文档」打 JD 职责第 2 条（职责同构，最硬对应点）
3. 自研项目压缩成半句
4. 「汽车电子团队」替代 AUTOSAR 术语
5. 「接受兼职」回应任职要求第 3 条
6. 「匹配」只在结尾出现一次，接行动请求

### ✅ 超短版

> 您好！我交付过一个近 4 个月的 Claude Code 项目——源码自动生成架构文档的流水线，设计、开发、测试、运维全周期负责，接受兼职。方便发您简历详聊吗？

## 模板选择决策

```
有商业交付经历？
├─ 是 → 主推版（商业交付钩子）+ 超短版
└─ 否 → 自研钩子变体 + 超短版
平台字数受限或用户要求更短 → 只出超短版
HR 已回复 → 展开版
已读不回超过 2 天 → 跟进版
```
